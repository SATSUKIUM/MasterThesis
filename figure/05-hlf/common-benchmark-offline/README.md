# run000668 offline benchmark (marq07)

`root -l -b -q plot.C` generates PDF only, with ../../pdf_output.hxx and pdfcrop. hist.root contains ROOT histograms; slice-ledger.csv.gz records every source slice, online decisions, event counts and track counts; clusters.csv contains all 8 cluster counts. Source records: common-benchmark/data/20261119-offline-benchmark and scripts/offline-benchmark. The remote source tree and ROOT intermediates are retained under /home/nestdaq/local/offline-benchmark-20261119.

The mother population is the same 20,000 replayed TF processed by LogicFilterCPU and TimeFrameSlicerByLogicTiming, with a pass-all HLF. It contains 152,880 slices and 260,330 built events. It is NOT the unsliced raw-event population of the earlier function check. Input slice membership is propagated through source_slice in EventBuilderOffline.C; Analyzer only adds source_entry, without changing its fitting logic. Offline execution is 96-way on marq07. TOF is all combinations of T1 and UTOF LR means, with abs(L-R)<=10ns. Time units are ns, UTOF-left reference1000ns.

Mask-after-calibration comparison: cuts select whole slices from one common calibrated mother population, so the histograms have correlated calibration smearing. Multiplicity N4 was also independently converted from the real filtered NestDAQ file and reconstructed:174,761 events,171,483 tracks. The common-calibration mask yields171,484 tracks. One event differs, with a reference timing crossing503432ns. TTimingChargeCalibrationProcessor adds gRandom->Uniform() to digital counts before conversion (lines112,125); no claim of bitwise equivalence is made.

BFT uses transferred analyzer.conf.default2 (run1230 BFT timing,run1745 hodoscope parameters), unretuned for run668. The usual default config produces zero BFT output because its BFT time window is absent and Bref segment2 is absent. The BFT plot and matching rates are conditional diagnostics, not calibrated intrinsic detector efficiencies. Straight extrapolation and window dependence are unvalidated. Errors are naive binomial and ignore overlapping slices.
